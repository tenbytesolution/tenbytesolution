# Company Profile Backend API

Backend API untuk website profile company dengan fitur admin panel.

## Fitur Utama

✅ **Authentication & Authorization**
- Login dengan JWT
- Role-based access (admin/editor)
- Refresh token mechanism

✅ **Admin Panel**
- Dashboard dengan statistics
- CRUD untuk semua modul
- Upload gambar dan file
- Manajemen konten website

✅ **Modul Konten**
- Company Profile
- Services (Layanan)
- Portfolio/Projects
- Testimonials
- Contact Messages
- Banners/Sections
- Blog/Articles

✅ **Public API**
- Endpoint untuk frontend website
- Optimized queries
- Pagination & filtering

## Teknologi

- **Runtime**: Node.js 16+
- **Framework**: Express.js
- **Database**: MySQL
- **Authentication**: JWT (JSON Web Token)
- **File Upload**: Multer
- **Validation**: Express Validator
- **Security**: Helmet, CORS, Rate Limiting
